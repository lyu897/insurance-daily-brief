# 보험 데일리 브리핑

보험 관련 뉴스를 하루 한 번 모아, 중요한 이슈만 짧게 보여 주는 웹사이트의 첫 화면입니다.

## 현재 포함된 것

- 오늘의 핵심 이슈와 분야별 필터
- 기사 검색으로 연결되는 원문 링크
- 날짜별 브리핑 아카이브 화면
- 휴대폰에서도 보기 좋은 반응형 디자인과 다크 모드

## 실제 자동화로 연결하는 순서

1. RSS 또는 사용 허가를 받은 뉴스 API에서 최근 24시간의 보험 기사를 읽습니다. 이 프로젝트는 Google 뉴스 RSS를 시작점으로 둡니다.
2. 제목, 발행 시각, 원문 링크만 저장하고 같은 이슈의 기사를 묶습니다.
3. AI가 각 묶음의 핵심 내용과 영향도를 2~3문장으로 요약합니다.
4. 요약 결과를 데이터베이스에 저장하고, 이 웹페이지가 그 데이터를 읽어 표시하게 합니다.
5. 매일 오전 정해진 시간에 이 과정을 실행합니다. 원한다면 새 브리핑 링크를 이메일로도 보냅니다.

## 매일 자동 갱신 켜기

이 폴더 자체를 GitHub 저장소로 올린 뒤 아래만 설정하면 됩니다.

1. GitHub 저장소의 **Settings → Secrets and variables → Actions**에서 `OPENAI_API_KEY`를 새 비밀 값으로 등록합니다.
2. **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다.
3. **Actions** 탭에서 `Daily insurance brief`를 열고 **Run workflow**를 한 번 실행합니다.

그 뒤에는 매일 한국 시간 오전 8시 30분에 뉴스 수집과 요약이 실행되고, `data/brief.json`이 갱신된 뒤 사이트도 자동 배포됩니다. 공개 주소는 GitHub Pages 설정 화면 또는 배포 작업의 결과에서 확인할 수 있습니다.

`OPENAI_API_KEY`는 코드나 화면에 넣지 마세요. GitHub 비밀 값으로 저장하면 작업에서만 사용할 수 있고, 로그에도 기본적으로 가려집니다.

정적 사이트라 추후 GitHub Pages 대신 Cloudflare Pages 또는 Vercel로 옮기거나, 원하는 도메인을 연결할 수도 있습니다.

기사 전문을 저장하거나 그대로 재게시하지 않고, 짧은 요약과 원문 링크를 제공하는 운영 방식을 권장합니다.
